# CodeAlpha_CGPA_calculator

## About the Project
This is a simple CGPA Calculator made using C++ programming language.  
It helps students calculate their GPA and CGPA based on grade points and credit hours.

This project is created as part of my CodeAlpha internship task.

## What This Program Does
- Takes student name as input
- Takes number of courses
- Takes course details:
  - Course name
  - Grade points (0 to 10)
  - Credit hours
- Calculates:
  - Total credits
  - Total grade points
  - GPA (Grade Point Average)
  - CGPA (Cumulative GPA)

## Formula Used
GPA = (Grade Point * Credit Hours) / Total Credit Hours

## Technologies Used
- C++
- iostream
- iomanip

## How to Run the Program

Step 1: Compile the code
g++ main.cpp -o CGPA_calculator

Step 2: Run the program
./CGPA_calculator

        OR

directly run it.

For Windows:
CGPA_calculator.exe
